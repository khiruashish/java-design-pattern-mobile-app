# Roadmap

> 📊 *Diagram: open this page on the website to see it drawn.*

## L0 · Orientation

**Experience:** Day 0 · **Pages:** 4 · [Open level](l0-orientation/index.md)

You're ready for the next level when you can:

- [ ] Explain what a design pattern is and name the three GoF categories
- [ ] Run a single-file Java 21 program from the terminal
- [ ] Read a class diagram and a sequence diagram

## L1 · Foundations

**Experience:** 0–1 yr · **Pages:** 12 · [Open level](l1-foundations/index.md)

You're ready for the next level when you can:

- [ ] Apply SOLID to a small class and explain which principle you used
- [ ] Implement Singleton, Factory Method, Builder, Strategy, Observer, Template Method, Adapter, Decorator and Facade from memory
- [ ] Say why you would NOT use a pattern in a given piece of code

## L2 · Practitioner

**Experience:** 1–3 yrs · **Pages:** 19 · [Open level](l2-practitioner/index.md)

You're ready for the next level when you can:

- [ ] Implement all 23 GoF patterns and pick between similar ones (Strategy vs. State, Adapter vs. Bridge)
- [ ] Wire an application with constructor injection and no container
- [ ] Unit test code that uses patterns with the right test doubles

## L3 · Professional

**Experience:** 3–6 yrs · **Pages:** 11 · [Open level](l3-professional/index.md)

You're ready for the next level when you can:

- [ ] Rewrite classic patterns with records, sealed types, pattern matching and lambdas
- [ ] Recognise the patterns inside the JDK and Spring and use them correctly
- [ ] Write thread-safe code with concurrency patterns and measure a pattern's cost with JMH

## L4 · Senior / Lead

**Experience:** 6–10 yrs · **Pages:** 9 · [Open level](l4-senior/index.md)

You're ready for the next level when you can:

- [ ] Choose and defend an application architecture (layered, hexagonal, modular monolith)
- [ ] Model a domain with aggregates, value objects and bounded contexts
- [ ] Design resilient, consistent distributed flows with sagas, outbox and circuit breakers

## L5 · Staff / Principal

**Experience:** 10–15+ yrs · **Pages:** 6 · [Open level](l5-staff-principal/index.md)

You're ready for the next level when you can:

- [ ] Set pattern standards, review checklists and fitness functions for many teams
- [ ] Explain the JVM mechanisms behind proxies, lambdas and safe publication
- [ ] Lead a legacy modernisation without a big-bang rewrite
